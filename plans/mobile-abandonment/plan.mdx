# Objective and done criteria

Abandon mobile development in this template. Remove the experiment's remote compute, storage, access configuration, delivery project and publishing credentials, then retire its branches and worktrees. Preserve the production web template and unrelated projects.

This document retains the original authorized cleanup sequence. `audit.json` contains the initial read-only investigation. Actual Alchemy teardown and provider verification are recorded in `cleanup.json` and reviewed in `../mobile-retirement/plan.mdx`. The identified AWS, Cloudflare and Expo experiment resources are retired, and all archived experiment worktrees and branches are removed. Do not mistake the original inventory below for resources still running.

Completion requires:

- The Android CloudFormation stack is deleted, its instance is terminated and its root EBS volume is absent. Its network resources and IAM role/profile are absent too.
- The Android Tunnel, DNS record, Access application/policies and verification service token are absent. Both abandoned PR stages have no Workers, D1 database, R2 bucket, custom domain or stage state left.
- The Expo project is deleted, the repository's Expo secrets are removed and the project-only publishing token is revoked. Cached preview applications no longer have a live experiment backend.
- Mobile-only development state is removed after confirming it has no remaining remote resources. The experiment branches and worktrees are retired only after their source, required teardown inputs and uncommitted work have been preserved.
- `main` remains web-only. Its production Workers, database, files bucket, web CI, R2 signing credentials and shared Alchemy state infrastructure still work.
- A post-cleanup provider inventory and later billing check distinguish zero experiment resources from older, unrelated storage and unverified subscriptions. Do not describe the entire account as cost-free while those remain.

Non-goals: deleting production web data, rewriting the web template, upgrading Alchemy or Effect, cancelling unrelated subscriptions, deleting shared account infrastructure, or erasing Git history. The owner subsequently authorized deletion of both older AWS backup sets; that explicit scope expansion and its completed absence checks are recorded in `cleanup.json`.

| Risk                                                                                 | Mitigation                                                                                                                                    |

| Stopped host continues to incur storage charges or can restart                       | Destroy its owner and verify disk absence, not merely `stopped`. Remove deployment/publication paths afterward.                               |
